画面引擎里每一帧做了什么

场景

节目包 scene 决定：自带示例演播室、你的背景图+前景图，或你写的场景脚本。主播站位和大屏位置都在这里配。

主播贴纸

每个表情是一整张图，不拼部件。说话时整张图跟着音量做 Y 轴弹性拉伸；换表情先压扁再弹起。没画的用占位小人。

推进大屏

镜头穿过两人推到屏幕，推到底时实机画面铺满全屏；收屏时再拉回全景，两人落地一跳。

字幕与要点

字幕按短语出现（样式由包装决定）；要点贴纸最多 3 个，有固定位置。

看点速报

可选的开头 20–30 秒整屏冷开场，接片头再进演播室。画面版式由你的包装决定。

包装

台标、新闻栏、板块转场、片头、灯光、特效都在一个包装脚本里；通用版是白字黑底的占位，换成你自己的设计。转场盖住画面的那一刻切好下一个场景。

所有命令都是 python pipeline.py <命令> --ep <本期文件夹>，细节见工具包 docs 文件夹。
