# 分镜与时间线规则（align / stage / audio 自动执行）

这些规则都已经写进 `pipeline.py` 和 `engine/film_ctrl.js`，正常情况不用手调。这里写清楚是为了：出问题时知道该改哪；用户提新要求时知道往哪加。

## 一、配音对齐（align）

输入：每位主播一条完整配音（mp3/wav）+ 配音软件导出的 srt（强烈建议有）。用户配音时是**按配音稿顺序一口气配完**的，稿子后来删改过也没关系。

1. 稿子每句（口播版文字）在该主播的 srt 文字流里做模糊匹配，得到「每个字 → 时间」的映射。匹配不到 60% 的句子报 ✘（多半是稿子改了但没重配）。
2. 句子的头尾不能伸进相邻的字幕条（那里可能是被删掉的句子）。
3. 用波形（10ms 能量，阈值 = 95 分位 × 5%）修边界：
   - 开头：吸收紧贴在前面、离上一句 ≥0.25s 的口吃/气口；
   - 结尾：字幕结束得早但声音还在，就延长到声音结束（不超过下一条字幕）；
   - **永远不比字幕范围短**（防止「话没说完就被打断」）。
4. 没有 srt 时只能按停顿切成句数相同的段，务必人工抽查。

## 二、排时间线（align）

句间空隙（`show.json → timing`，单位秒）：
| 情况 | 默认 |
|---|---|
| 换人说 | 0.36 |
| 同一人连说 | 0.42 |
| 上一句以「——」结尾（被打断/抢话） | 0.14 |
| 新板块（中间要放转场） | 1.45 |
| 从演播室进入大屏 | ≥0.5 |
| 片头留白 / 片尾留白 | 2.8 / 2.4 |
| `【独奏:x】` | 额外 +x |
| 看点速报第一句 / 看点速报结束到正片第一句 | 0.8 / 3.3（含退场和片头，见 hook_rules.md） |

两条人声轨重叠必须为 0（align 最后会报）。

## 三、自动分镜（stage）

**表情**
1. 句首 `【贴纸】` > 动作提示里的关键词（`hosts.X.direction_words`，如「掰手指」→数数）> 在大屏时默认「讲解」> 主播默认表情。
2. 句中 `【贴纸】` 在说到那个字时切换。每次切换贴纸会压扁再弹起；说话时贴纸随音量做 Y 轴弹性拉伸（具体规则和参数见 animation_rules.md）。
3. `【反应】` 改另一位主播的表情。

**镜头**（没写 `【镜头】` 且不在大屏时）
- 板块第一句 → 全景
- 短句（≤14 字）接在别人后面 → 全景（对话感）
- 带「！」的句子 → 说话人特写
- 其他 → 全景

**大屏**
- 进入：镜头加速推进屏幕 + 视差，0.55s 时屏幕从待机画面切到实机画面（包装层收到 `screen_in` 事件，可以在这里做闪光）；退出：屏幕回到待机画面，镜头拉回两人中间，主播落地弹一下（`screen_out` 事件）。
- 板块开头的大屏用转场盖住，直接切入（没有推进动画）。
- 大屏期间角落显示说话人的小贴纸；主播层完全透明（不能透到画面上）。
- 片段编号 `wNNsM`：第 NN 次进入大屏的第 M 个画面。截片段、原声、帧目录都用这个编号。

**字幕**：口播版文字按标点切成短语（≤22 字），按字的时间显示；同一句的后续短语不再重复滑入动画。

**要点贴纸**：最多 3 个同时在场，有固定槽位；进出大屏时清空。

**转场（板块）**：长什么样由包装决定（package_rules.md）；被转场盖住的瞬间切好下一个场景。

## 四、声音（audio）

- 音效全部程序合成（`sfxlib.py`）：贴纸切换 pop、要点 boing、进出大屏 whoosh/zap、拍桌 thump、信息牌 ding 等。不加 BGM（需要就后期配）。
- 原声垫底：只有标了「原声」的片段。响度统一到 RMS 0.12，乘 `audio.orig_level`（默认 0.32；有 `【独奏】` 的段 ×1.7），主播说话时压低 62%（起 0.45 / 收 0.03 每 10ms），进大屏 0.55s 后淡入、出大屏 0.25s 淡出，同一窗口内换段 0.15s 交叉淡化。
- 最后整体归一化到 -0.45 dBFS 峰值。

## 五、改规则的位置

| 想改 | 位置 |
|---|---|
| 空隙时长 | `show.json → timing` |
| 原声音量 | `show.json → audio.orig_level` |
| 动作词 → 表情 | `show.json → hosts.X.direction_words` |
| 表情名 → 贴纸 | `show.json → hosts.X.emotions` |
| 换到哪张贴纸算大动作 | `show.json → hosts.X.fxkind`（贴纸编号 → "big" / "soft"），不写按文件名猜 |
| 贴纸上的「手」在哪（给包装放粒子） | `show.json → hosts.X.anchors`（贴纸编号 → [x,y]，0–1 相对坐标） |
| 镜头规则 | `pipeline.py → cmd_stage` 的 camera default rules |
| 弹动、换表情、镜头运动的手感 | `show.json → animation`，参数表见 animation_rules.md |
| 灯光、粒子、特效、转场、新闻栏 | 你的包装脚本，见 package_rules.md |
| 场景、站位、屏幕位置 | `show.json → scene`，见 scene_rules.md |
| 动画的新动作 | `engine/film_ctrl.js`（改完直接生效，不用编译） |
