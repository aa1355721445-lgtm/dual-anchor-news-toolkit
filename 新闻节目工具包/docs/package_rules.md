# 节目包装：怎么做你自己的

「包装」是节目除了布景和主播以外、让它看起来像一档节目的东西：台标、新闻栏（字幕条）、板块转场、片头、看点速报的画面、灯光、特效。它们决定了节目的辨识度，所以**通用版不提供任何现成设计**，只给「素白占位」：白字黑底，保证流水线能跑通出片、让你看清每一层什么时候出现。

全部包装都在**一个脚本**里：`新闻节目工具包/engine/package.js`（素白占位版）。做你自己的：

1. 把它复制到 `节目包/包装/package.js`；
2. show.json 加一行 `"package": "包装/package.js"`；
3. 一个函数一个函数地换成你的设计。`包装/` 文件夹里的图片、字体会一起拷进渲染网页，脚本里用 `pkg/文件名` 访问（在 `load` 里载入）。
4. 每改一点就跑 `pipeline.py scene --show 节目包` 看预览；做完一期后用 `render --range 0,40` 看带声音的片段。

放在节目包里的好处：工具包升级（`setup --update`）不会覆盖你的包装。

## 一、每一层画在哪里

每一帧按这个顺序画（后画的盖住先画的）：

| 顺序 | 层 | 谁画 | 跟镜头动吗 |
|---|---|---|---|
| ① | 场景后景（墙、地面、屏幕） | scene（scene_rules.md） | 动 |
| ② | 大屏上的实机画面 | 引擎 | 动 |
| ③ | **`behindHosts`** 主播身后的灯光 | 包装 | 动 |
| ④ | 两位主播 | 引擎 | 动 |
| ⑤ | 场景前景（主播台） | scene | 动 |
| ⑥ | **`frontOfHosts`** 主播前面的粒子、漫符 | 包装 | 动 |
| ⑦ | 角落小主播、信息牌、要点贴纸 | 引擎（内置） | 不动 |
| ⑧ | **`overlay`** 整屏光斑、调色、暗角 | 包装 | 不动 |
| ⑨ | **`logo`** 台标 | 包装 | 不动 |
| ⑩ | **`lowerThird`** 新闻栏（栏目名、说话人、字幕、快讯、时钟） | 包装 | 不动 |
| ⑪ | **`effects`** 屏幕特效（白闪、速度线、震屏标记…） | 包装 | 不动 |
| ⑫ | **`sectionCard`** 板块转场 | 包装 | 不动 |
| ⑬ | **`hook`** 看点速报（整屏） | 包装 | 不动 |
| ⑭ | **`sting`** 片头标题 | 包装 | 不动 |
| ⑮ | 片尾最后 0.9 秒淡出到黑 | 引擎 | — |

「跟镜头动」的层坐标是 1920×1080 世界坐标，镜头推近时跟着放大；「不动」的层是屏幕坐标，永远在画面同一个位置。

另外三个**事件函数**不画东西，是引擎在某个时刻通知你：
- `effect(name, who)`：稿子里写了【特效:xxx】（见第三节）。
- `onSticker(c, id, big)`：主播换表情的那一刻（`big` = 大动作）。适合放一小撮粒子。
- `event(name, data)`：`'screen_in'` 开始推进大屏、`'screen_out'` 开始拉回、`'section'` 板块转场开始、`'sting'` 片头开始。

## 二、每个函数能拿到的数据

这些都是全局变量/函数，包装脚本里直接用（只读，除非特别说明）：

| 名字 | 内容 |
|---|---|
| `T` | 当前秒数（渲染时每帧 +1/30） |
| `W` `H` | 1920、1080 |
| `SHOW0` / `EP0` | show.json / episode.json（节目名、频道名、主播、`ui` 里你自己加的参数；本期的 `ticker`、`date`、`sting_sub`） |
| `SPK.A` `SPK.B` | 主播资料：`name` `role` `c1` `c2` `glow` |
| `curSub()` | 当前这条字幕 `{who, text, t0, noSlide}`，没人说话时是 null。`noSlide=true` 表示同一个人接着说下一句（可以不重复做名字的进场动画） |
| `SUBS` | 所有还在显示/正在退场的字幕（做退场动画用，`outAt` 是开始退场的时刻） |
| `SECTION` / `secT` | 当前栏目名 / 换栏目的时刻 |
| `TICKER` | 快讯数组（episode.json → ticker） |
| `clock()` | 节目时钟（Date，从 episode.json → date 开始走） |
| `CUR` | 正在说话的主播 `'A'`/`'B'` |
| `lipSample(CH.A).level` | 主播此刻的配音音量 0–1（做随声音变化的灯光） |
| `anchorPt(CH.A, 贴纸编号或'', fx, fy)` | 主播贴纸上某一点在画面上的位置 `{x,y,sc,screen}`。`fx/fy` 是人物范围的比例，`(.5,.15)` ≈ 头顶；`screen=true` 时这点在屏幕层（主播缩在角落或在看点速报里） |
| `clipState` | 大屏状态：`off` / `opening` / `on` / `closing` |
| `cam` | 镜头 `{x,y,z,r}`：中心、放大倍数、倾斜角 |
| `EYE` | 板块转场 `{t0, big, small, n}`：开始时刻、大字、小字、第几个板块；没有转场时是 null（**画完要自己把过期的 EYE 设回 null**，素白版里有示范） |
| `STING_T` | 片头开始的时刻 |
| `hookActive()` / `hookState()` | 看点速报是否在进行 / 它的全部信息（第五节） |
| `window.STATION_IMG` / `window.TITLE_IMG` | 节目包 `品牌/` 里的台标图、标题图（没有就是 null） |
| `STKIMG.A[编号]` | 主播贴纸（`{img, bb}`），转场、片头里想让主播露脸可以用；招牌表情编号在 `SHOW0.hosts.A.eyecatch` |
| `drawStickerAt(g, CH.A, x, 脚底y, 高度)` | 按引擎的弹簧动画把主播画到任意位置 |
| `kwPill(g, k, x, y)` | 画一个要点贴纸（引擎内置样式） |

可以写入的：`fx.shakeX` / `fx.shakeY`（整个世界层偏移，做震屏；**同时把 `fx.shakeA` 设成当前振幅（像素），镜头会自动多放大一点，四边不露黑**，震完设回 0）、`fx.punch(0.08)`（镜头轻推一下）。

小工具（core.js）：`rrect` 圆角矩形、`fitText` 字太长自动缩小、`easeBack` 回弹缓动、`lerp` `clamp` `mix` `hex` `rgb` `rnd`、`UIF` 中文字体栈。

## 三、各层的硬约束和做法建议

### 台标 `logo`
- 位置：左上角。场景那边会避开左上角 520×100 的区域。
- 有台标图（`品牌/station.png`）时素白版直接贴；没有就写频道名。台标建议透明底，放在亮背景和暗背景上都要看得清。

### 新闻栏 `lowerThird`
- **必须贴着画面底边、左右通栏**（下面和两侧不露背景）——这是新闻节目的观感底线。
- 高度自己定，定了以后写进 `show.json → ui.lower_third_height`（素白版是 120）：`scene --export` 的参考线和场景编辑器都按这个高度标出「会被盖住的区域」，做场景的人就知道主播的脸别放进去。
- 字幕要**整句显示完整**：长句已经被流水线按 `ui.subtitle_max_chars`（默认 22 字）切成几条，你只需要保证一条 22 个字放得下（`fitText` 可以兜底缩字）。
- 说话人名字用主播的代表色 `SPK[who].c1` 能让观众一眼分清是谁在说。
- 常见做法：上面一行栏目名（`SECTION`，换栏目时有个进场）、中间一行「名字 + 字幕」、最下一行滚动快讯（`TICKER`，速度自己定，参数放 `SHOW0.ui`）、左侧一块放节目标题图和时钟（`clock()`）。

### 板块转场 `sectionCard`
- 时长 **1.45 秒**，从 `EYE.t0` 开始。
- **0.3–1.05 秒之间必须整屏不透明地盖住画面**：引擎在 0.5 秒时把镜头和大屏直接跳到下一板块的状态，成片分段也切在 0.65 秒处，这段时间露出来就会看到画面跳。
- 进场、退场多快多花随你。可以用 `EYE.big`（大字）、`EYE.small`（小字，来自稿子里 `## 大字 · 小字`）、`EYE.n`（第几个板块）、主播的招牌表情贴纸。
- 第一个板块和紧跟看点速报的板块没有转场（前面是片头）。

### 片头 `sting`
- 从 `STING_T` 开始 **2.7 秒**，期间画面后面是演播室全景在慢慢推近。
- 有看点速报时，片头紧跟在看点速报后面，所以开头要盖住看点速报退场的那一下。
- 常见做法：节目标题图（`window.TITLE_IMG`）弹出 + `EP0.sting_sub` 一行副标题，最后让开露出演播室。

### 看点速报 `hook`
- 整屏、盖住演播室，从 0 秒到看点速报结束后 0.45 秒（`hookActive()` 为真的这段）。`hookState()` 给你：

| 字段 | 内容 |
|---|---|
| `who` | 正在说的主播 |
| `mode` | `'clip'` 有实机画面 · `'mystery'` 不配画面（卖关子） · `'outro'` 收尾句 |
| `n` / `total` | 第几条 / 一共几条 |
| `title` | 栏目名（`ui.hook_title`） |
| `bubble` / `bubbleOn` / `bubbleAge` | 稿子里【气泡:…】的字 / 现在该不该显示 / 已显示多久 |
| `itemAge` | 换到这一条已经多久（做每条的进场动画） |
| `sub` | 当前字幕 |
| `keywords` | 这一条的要点（`kwPill` 能直接画，`slot` 是叠放顺序） |
| `out` | 结束后的退场进度 0→1 |
| `footage(g,x,y,w,h)` | 把当前实机画面铺满到一个框里（没有画面时返回 false） |
| `host(g,who,x,脚底y,高度)` / `hostX(who)` | 画说话的主播 / 换人时主播滑进滑出的横坐标 |
| `hostPos` | `ui.hook_host` 的位置 |

- 稿子的写法和节奏在 script_format.md 第六节、hook_rules.md；画面版式完全由你决定。

### 灯光 `behindHosts` / `overlay`
- 灯光会让演播室有层次，但都是可选的。思路：主播身后跟着主播代表色（`SPK[w].glow`）的背光、随配音音量（`lipSample`）微微变亮；大屏附近一团泛光（中心用场景的 `SCENE.glow`）；`overlay` 里做整体调色和暗角。
- 推进大屏时（`clipState!=='off'` 且 `cam.z` 很大）世界层的灯光应该淡掉，不然会糊在实机画面上。

### 特效 `effect` / `effects` / `frontOfHosts`
稿子里能写的特效名（【特效:拍桌、闪光】可以一次写几个），引擎原样转给 `effect(name, who)`：

| 稿子里写 | name | 一般怎么做 |
|---|---|---|
| 拍桌 | `slam` | 震屏（写 `fx.shakeX/Y`，几帧内衰减）+ 主播脚下一圈冲击 |
| 闪光 | `flash` | 整屏白闪一下 |
| 速度线 | `lines` | 从中心放射的线 |
| 冲击 | `punch` | 镜头猛推一下（`fx.punch(0.1)`） |
| 汗 / 问号 / 感叹 / 生气 / 脸红 / 闪亮 | `sweat` `question` `exclaim` `anger` `blush` `sparkle` | 主播头边冒一个漫符（位置用 `anchorPt(CH[who],'',.82,.1)`） |

素白版只在画面上标一行「【特效：拍桌】」，告诉你这里该有一个特效。做法：`effect()` 里记下「什么特效、谁、什么时候」，在 `frontOfHosts`（跟镜头动的，比如漫符、冲击圈）或 `effects`（屏幕上的，比如白闪、速度线）里按时间画出来、过期删掉。
- 世界层里的东西用 `anchorPt` 拿到的 `screen` 判断该画在哪层：`screen=true` 时主播在屏幕层（角落小主播、看点速报），要在 `effects` 里画。
- 漫符图片放 `包装/`，在 `load` 里载入。

## 四、引擎内置、通用版保留的部分

这些不在 package.js 里，样式在 `engine/film_ctrl.js`，想改也可以直接改：
- **要点贴纸**：稿子里【要点:文字|颜色】，圆角彩色胶囊，颜色 gold pink blue mint purple red；每位主播同时最多 `ui.keyword_max` 个，停留 `ui.keyword_hold` 秒；在演播室里出现在说话主播的外侧上方，大屏全屏时排在右上。
- **信息牌**：稿子里【信息牌:上行 · 下行】，只在大屏放画面时出现，右上角白色圆角牌。
- **角落小主播**：大屏全屏时，正在说话的主播缩到右下角（位置 `ui.corner_host`）。
- **封面**：`templates/cover/cover.html`，文字在 episode.json → cover 里改，版式改模板。
- **音效**：`scripts/sfxlib.py` 程序合成（换表情、要点、推大屏、转场、特效名都有对应的声音），整体音量 `audio.sfx_level`。想用自己的音效文件可以改 `pipeline.py` 的 `cmd_audio`。

## 五、做完的检查

- [ ] 新闻栏贴底通栏，22 个字的字幕完整显示，两位主播的名字颜色分得清
- [ ] 转场在 0.3–1.05 秒之间整屏不透明（`render --stills` 截转场开始后 0.5 秒那一帧看）
- [ ] 片头盖住了看点速报的退场
- [ ] 推进大屏全屏时，实机画面上没有糊上世界层的灯光、粒子
- [ ] 稿子里写过的每种【特效】都有样子（不再出现「【特效：xxx】」占位字）
- [ ] 包装脚本放在节目包 `包装/` 里、show.json 写了 `package`，`setup` 不再提示「素白占位」
