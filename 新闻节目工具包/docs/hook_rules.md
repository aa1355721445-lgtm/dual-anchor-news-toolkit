# 看点速报（可选的开头爆点预告）

每期最前面先用 20–30 秒把本期最有看点的几件事抛出来，留住观众，再进片头和演播室正片。
**稿子怎么写**见 script_format.md 第六节；这一篇写**时间线、声音、参数和代码位置**。**画面长什么样由你的包装决定**（package_rules.md 的 `hook`），通用版是素白占位：左边实机画面框、右边说话的主播、气泡和字幕用白字。

## 一、在整期里的位置

```
0.0s ── 看点速报（整屏，盖住演播室）── 结束后 0.42s 退场 ──┐
                                                           ├─ 片头（2.7s）
                                                           └─ 演播室推镜 → 正片第一个板块
```
- 稿子里第一个板块写 `## 看点速报`，程序就认它是看点速报（别名在 `show.json → ui.hook_sections` 里加）。不写就没有看点速报，片头在 0 秒。
- 第一句从 `timing.hook_start` 秒开始（默认 0.8）；看点之间用正常的换人 / 同人间隔，节奏比正片紧。
- 最后一句说完后留 `timing.gap_after_hook` 秒（默认 3.3）再进正片第一句：这段里看点画面退场、片头出现。
- 看点速报**不出板块转场**，正片第一个板块也不出（片头就是转场）；板块序号从正片第一个板块算 01。
- 章节：`00:00 看点速报`，正片第一个板块从片头出现那一刻算起。分段切口也放在那里。

## 二、每一句带给画面的信息

流水线把看点速报里的每句话整理成这些字段，交给包装层的 `hookState()`：

| 字段 | 来自稿子 | 用途 |
|---|---|---|
| 第几条 / 共几条 | 收尾之前每句算一条 | 计数 |
| `mode` | 有 🎬 → `clip`；没有 🎬 → `mystery`（卖关子）；带【收尾】的句子 → `outro` | 框里放实机画面 / 悬念卡 / 收尾语 |
| 气泡 | 【气泡:文字】；没写时自动取这句开头的感叹词（「什么？！」「等等！」） | 主播的震惊反应 |
| 要点 | 【要点:文字|颜色】 | 这句一开口就弹出（不用写锚点） |
| 表情 | 【贴纸:表情名】 | 主播换表情 |

## 三、声音

- 开场一声 swoosh；每条看点开口时 whoosh + hit，有气泡时再加一声 boing。
- 看点里的 🎬 默认静音；标了「原声」的段照常垫底（规则同正片）。
- 片头的音效跟着片头走（在看点速报结束后）。

## 四、可调参数（`show.json`）

| 位置 | 键 | 默认 | 作用 |
|---|---|---|---|
| `ui` | `hook_sections` | `["看点速报"]` | 哪些板块名算看点速报 |
| `ui` | `hook_title` | 看点速报 | 栏目名（包装层显示在哪由你定） |
| `ui` | `hook_outro` | 精彩内容 · 请继续观看 | 收尾时框里的字 |
| `ui` | `hook_host` | `{x:1560, base:1150, h:900}` | 说话主播的位置和大小（你的包装可以不用） |
| `timing` | `hook_start` | 0.8 | 第一句从第几秒开始 |
| `timing` | `gap_after_hook` | 3.3 | 最后一句到正片第一句的间隔（含退场和片头） |

## 五、代码在哪

| 部分 | 位置 |
|---|---|
| 认出看点速报板块 | `scripts/pipeline.py → cmd_parse`（`part`、`hook` 字段） |
| 时间线 | `cmd_align` 里 `hook_start` / `after_hook` |
| 气泡、模式、编号、片头时间 `sting_t` | `cmd_stage` 的「看点速报」段 |
| 音效 | `cmd_audio` |
| 章节和分段 | `cmd_encode`（`first_after_hook`） |
| 状态（谁在说、换人滑入滑出、要点、气泡计时） | `engine/film_ctrl.js` 的「看点速报」段：`hookLine`、`hookX`、`hookState` |
| 画面 | 你的 `package.js → hook()` |

## 六、检查（交付前）

- [ ] 看点速报只讲本期正片里有的内容，数字和正片一致
- [ ] 两人轮流，4–6 条，总长 20–30 秒，收尾句每期不同
- [ ] 每条看点的画面对得上，没有官方主持人出镜
- [ ] 结束时 看点画面 → 片头 → 演播室，衔接没有黑帧
- [ ] 章节第一条是 `00:00 看点速报`
