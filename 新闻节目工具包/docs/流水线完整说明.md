## 1. 一页看懂

**成品**：一条几分钟的双主播新闻节目视频（1080p 30 帧）。

```
0:00  看点速报（可选，20–30 秒）  本期最有看点的 4–6 件事，两位主播轮流抛出来
      片头（2.7 秒）
      正片                         演播室里两位主播播报
                                   ├ 讲到具体内容时，镜头推进大屏，全屏播官方实机画面
                                   ├ 字幕、要点贴纸、表情切换、音效
                                   └ 板块之间有转场
      片尾                         收尾 → 淡出
另附：16:9 和 4:3 两张封面、章节时间点
```

**通用版里有什么、没有什么**

| 部分 | 通用版 | 你要做的 |
|---|---|---|
| 流程、对齐、分镜、渲染、混音、编码、封面模板 | 完整可用 | — |
| 主播动画（说话弹动、换表情弹跳）、镜头运动、推大屏 | 完整可用 | 可调参数 |
| 要点贴纸、信息牌、角落小主播、音效 | 内置 | 可选改 |
| 主播贴纸 | 没有，用占位小人 | 画两位主播的贴纸（每个表情一整张图） |
| 演播室场景 | 一个中性的示例演播室 | 换成你的背景图/前景图，或写场景脚本 |
| 包装：台标、新闻栏、转场、片头、看点速报画面、灯光、特效 | 素白占位（白字黑底） | 在一个包装脚本里做你的设计 |

**谁做什么**

| | Claude | 用户 |
|---|---|---|
| 定节目（一次） | 填配置、出场景预览、陪你把场景和包装做出来 | 定节目名和主播、画贴纸、画场景、定包装风格 |
| 找素材 | 找官方视频、拿字幕、截图核对、写关键点汇总 | 需要截片段时提供原视频 |
| 稿子 | 按人设写稿，检查格式，列贴纸需求 | **审稿**，定梗位，需要时画新贴纸 |
| 配音 | 生成每人一份纯台词的配音稿 | **配音**，导出音频和字幕 |
| 制作 | 对齐、分镜、截片段、渲染、编码、封面、检查 | 云端时运行截片段脚本 |

**核心思路**：稿子是唯一的「剧本」。稿子里的每句话、每个【标记】、每个 🎬，经过工具一步步变成时间线、分镜数据、声音和画面。改了哪里，就从那一步往后重跑。

## 3. 初始化（setup）

```
python 新闻节目工具包\scripts\pipeline.py setup --install
```

1. **解压安装包**：在项目文件夹（和下一层）里找含 `新闻节目工具包/`、`节目包/` 的压缩包，解压合并；根目录的安装包挪进 `节目工具包打包/`。已有的文件不覆盖；`--update` 只更新工具包，**节目包永不覆盖**。
2. **列出工作区分区**。
3. **检查运行环境**：Python 库（numpy、pillow）、ffmpeg、Node.js、playwright、chromium、中文字体。`--install` 自动装 Python 库和 playwright。
4. **检查节目包**：节目名是不是还是占位、表情表里的贴纸缺哪些（缺的渲染时用占位小人）、场景配置和图片、包装是不是还是素白占位、品牌图、人设档案、术语对照。
5. **写 `工作区.json`**。
6. **列出还缺什么 + 下一步命令**。

## 4. 节目只做一次：主播、场景、包装

### 4.1 主播
在 show.json 的 `hosts.A`（左）和 `hosts.B`（右）里填名字、稿子里用的简称、代表色、贴纸文件名前缀、**表情表**（写稿用的表情名 → 贴纸编号）。贴纸规格见 config.md：一个表情一整张图，透明底，同一位主播的所有贴纸画风大小一致，不需要对齐（程序按脚底摆放）。贴纸可以晚点画，第一期稿子写完跑 `stickers` 就知道要画哪些。

### 4.2 场景（scene_rules.md）
- `scene --show 节目包`：不需要任何一期素材，直接用真引擎渲染 6 个镜头的预览图。
- 三种场景：`example`（自带示例）、`image`（背景图 + 前景图，不用写代码）、`code`（自己写场景脚本，可以做会动的布景）。
- 最快的路：`scene --export` 把示例场景导出成 背景 / 前景 / 参考线 三张图 → 在绘图软件里照参考线重画 → 改成 `image` 类型 → 用 `场景编辑器.html` 对好大屏和主播的位置。

### 4.3 包装（package_rules.md）
- 包装全在一个脚本里：复制 `engine/package.js` 到 `节目包/包装/package.js`，show.json 写 `"package": "包装/package.js"`，然后一个函数一个函数换成你的设计。
- 每个函数什么时候被调用、能拿到什么数据、有哪些硬约束（新闻栏贴底、转场 0.3–1.05 秒必须整屏盖住……）都在 package_rules.md 里。
- 不做也能出片：素白占位是白字黑底，特效位置会标出「【特效：xxx】」提醒你这里该有东西。

## 5. 每期十步

所有命令：`python <工具包>\scripts\pipeline.py <命令> --ep <本期文件夹>`（路径写绝对路径）。

**第 0 步 选运行位置**：优先本机（`setup` 全绿就全程本机）；不行再走云端（素材拷进工作区，原视频太大时片段由用户在本机用脚本截，成片有大小上限时 `split_mb` 按板块切段）。

**第 1 步 建期** `init --ep <项目>\第1期 --show <项目>\节目包 --version 2.1`：生成文件夹、`episode.json`（XX 占位改成本期内容）、`稿子_模板.md`（已填好主播简称）。`doctor --ep` 列出还缺什么。

**第 2 步 找视频**（浏览器）：在官方账号投稿里找目标视频，或用用户给的链接（sourcing_bilibili.md）。

**第 3 步 字幕 + 截图核对**（浏览器）：字幕 JSON → `bsub` 转成 `原视频字幕.srt`；按字幕挑时间点截图，核对名字和数字。

**第 4 步 关键点汇总**：逐条「事实 + 原视频时间点 + 截图」。AI 字幕同音错字多，名词以画面为准。`speechmap` 找「官方没在讲解」的时段（留原声用）。新术语补进 `术语对照.md`。

**第 5 步 写稿**：读人设档案和术语对照；从 `稿子_模板.md` 起手；（可选）第一个板块写 `## 看点速报`；每句配好 🎬、表情、镜头、要点等标记；`parse` 到没有 ⚠；`stickers` 生成 `贴纸需求.md`。
⏸ **用户审稿**。

**第 6 步 配音稿** `dub`：每人一份纯台词，数字转汉字（20 抽→二十抽、2 个→两个、第 2→第二、50%→百分之五十、2026 年→二零二六年、1v1→一对一），去掉标记和动作；附 `对话顺序对照.md`。斜杠日期、英文缩写要在稿子里写成汉字。
⏸ **用户配音**：每人一条完整音频 + 带时间码的字幕（srt），放进 `配音/`。

**第 7 步 对齐 + 分镜** `align` → `stage`：每句台词在配音里找到准确位置，排成两人对话的时间线（**人声重叠必须是 0 毫秒**）；再补全表情、镜头、大屏片段编号、字幕短语、要点时间，生成 `film.json`。

**第 8 步 截片段** `clips`：生成截片段脚本和清单；每段从时间点起截「需要时长 + 2.5 秒」，缩放补边到 1280×720，保留声音。本机有原视频就 `clips --cut`。

**第 9 步 渲染出片**：
```
prepclips          拆帧（每秒 30 张）+ 拆音轨 + 检测黑边
audio              合成音效 + 原声垫底 + 人声 → master.wav
render --stills 1.5,30,95     先截几张看
render             全片逐帧渲染（中断用 --keep 续渲）
encode             编码成片 + 章节.txt（超过 split_mb 按板块切段）
```

**第 10 步 封面 + 检查**：`cover` 出两张封面；`qa` 自动查人声重叠、缺片段、空字幕、帧齐不齐、还在用占位图的贴纸，并拼出关键帧图；再按 qa_checklist.md 亲眼看、亲耳听。

**交付**：成片几段、多长；封面两张；章节时间点；哪些还是占位。改版用 `--tag v2` 出新文件名。

## 6. 稿子标记速查

```markdown
## 板块名 · 副标题                     一个板块（出转场；可选的第一个板块「看点速报」）

🎬 18:33–18:47                         下一句开始推进大屏播这段原视频
🎬 18:40–19:10 原声 说明                同上，并保留原声
🎬 37:01 → 37:17@锚点 → 37:33@锚点      一句话里说到锚点时换画面
🎬 续                                   下一句继续留在大屏
🎬 关                                   明确回演播室

A：（动作提示）【标记】台词【句中标记】台词
```

| 标记 | 作用 |
|---|---|
| `【贴纸:表情】` | 说话人换表情（句首立即，句中说到那里换） |
| `【反应:表情】` | 另一位（听的人）换表情 |
| `【镜头:全景/特写/倾斜/推近/特写B】` | 镜头；不写按规则自动选 |
| `【特效:拍桌、闪光、速度线、冲击、汗、问号、感叹、生气、脸红、闪亮】` | 特效事件，样子由包装决定 |
| `【要点:文字@锚点\|颜色】` | 要点贴纸，说到锚点弹出；颜色 gold/pink/blue/mint/purple/red |
| `【信息牌:上行 · 下行】` | 大屏上的信息牌 |
| `【独奏:秒】` | 这句前先空几秒只放原声 |
| `【收屏@锚点】` | 说到锚点时从大屏回演播室 |
| `【气泡:什么？！】` | 看点速报里的震惊气泡文字（不写自动取句首） |
| `【收尾】` | 看点速报的收尾句 |
| `【梗位：…】` | 单独一行，讨论用占位，不进成片 |

完整规则见 script_format.md。

## 7. 原理：数据在工具里怎么流

```
稿子.md ──parse──▶ script.json ──dub──▶ 配音稿
                        │
配音 mp3+srt ──align──▶ timeline.json + voice_A/B.npy
                        │
               stage ──▶ film.json ◀── 片段帧（prepclips）
                        │                    │
               audio ──▶ master.wav ◀── 片段原声
                        │
               render ─▶ frames/*.jpg（渲染页在无头浏览器里逐帧画）
                        │
               encode ─▶ 成片.mp4 + 章节.txt
```

**parse**：逐行读稿子：`##` 是板块，`🎬` 是片段，`名字：` 是台词。（动作）和【标记】被抽走，标记连同它在句中的**字位置**一起记下（句中标记在说到那个字时触发）。每句记下所属板块和是否属于看点速报。遇到「术语 / 待讨论 / 附录 / 备注」标题后面都不解析。

**align**：
1. 找位置：每句的口播文字（数字已转汉字、去标点）在这位主播的配音字幕文字流里模糊匹配，得到「每个字在配音里第几秒」；稿子跳过了一大段录音时会往后扫描找最像的位置；匹配不到 60% 报 ✘。
2. 修边界：用波形能量找真实声音：句头吸收紧贴在前面的气口；句尾声音还在就延长；**永远不比字幕范围短**（防止话被截断）；不伸进相邻字幕条。
3. 排时间线：换人 0.36 秒、同人 0.42 秒、被打断 0.14 秒、新板块 1.45 秒、进大屏至少 0.5 秒；看点速报从 0.8 秒开始，结束后留 3.3 秒给退场和片头（都在 `timing` 里可调）。
4. 拼人声：剪出每句音频（头尾淡入淡出）放到时间线上，得到两条人声轨，检查重叠为 0。

**stage**：
- 字幕：口播文字按标点切成 ≤22 字的短语，按字的时间出现。
- 表情：句首【贴纸】> 动作提示里的关键词（`direction_words`）> 在大屏时「讲解」> 默认表情；句中【贴纸】换算成绝对时间。
- 镜头：板块第一句、短句接话 → 全景；带「！」→ 说话人特写；【镜头】优先。
- 要点、特效、收屏：锚点换算成秒。
- 大屏窗口：连续带 🎬 的句子合成一个窗口，每个画面编号 `wNNsM`，记下开始时间、时长、是否原声、黑边裁切。
- 看点速报：气泡文字、模式（实机 / 悬念 / 收尾）、编号、片头时间 `sting_t`。
- 音量曲线：两条人声按每秒 60 格算 RMS，归一化到 0–1，给弹动用（包装也能读）。
- 节目包和本期的公开信息（主播、颜色、场景、界面参数、快讯、日期）一起写进 `film.json`。

**prepclips**：每段片段拆成每秒 30 张 1280×720 的 jpg 和一条音轨；`cropdetect` 找出整段都是黑的上下/左右黑边，渲染时裁掉铺满。

## 8. 画面引擎是怎么搭的

### 8.1 总体结构
整个画面是**一个网页里的 canvas 用代码逐帧画**的，画布 1920×1080。渲染页 `studio.html` 按顺序载入四个脚本：

```
core.js       核心：画布、小工具、主播贴纸、镜头状态、场景接口、主循环、载入
pkg/package.js 包装层：你的（或素白占位）台标、新闻栏、转场、片头、看点速报、灯光、特效
scene/scene.js 场景：示例 / 图片场景 / 你的场景脚本（调用一次 defineScene）
film_ctrl.js  节目控制器：读 film.json，按时间驱动一切
```
渲染时 `pipeline.py` 把这几个文件、贴纸、品牌图、场景文件夹、包装文件夹、片段帧一起拷进 `work/site/`，开一个本地网页服务给渲染器打开。改 engine 里的 js 不需要编译，下次渲染直接生效。

三块各管各的：
- **场景**只管布景本身（墙、地面、屏幕、主播台），并告诉引擎屏幕和主播的位置。
- **包装**只管节目的外观（台标、字幕条、转场、片头、灯光、特效）。
- **引擎**管时间线、动画、镜头、实机画面、要点贴纸，把需要的状态交给包装。

### 8.2 每一帧的合成顺序
```
清屏
镜头变换（平移到镜头中心、旋转、缩放；包装可以加震屏偏移）
  ① 场景后景                    scene.back()
  ② 大屏实机画面（推进大屏时）  引擎
  ③ 主播身后的灯光              package.behindHosts()
  ④ 两位主播（视差；推大屏时逐渐透明）
  ⑤ 场景前景（视差系数 1.15）   scene.front()
  ⑥ 主播前面的粒子/漫符         package.frontOfHosts()
退出镜头变换（以下是屏幕坐标，不跟镜头动）
  ⑦ 角落小主播、信息牌、要点贴纸
  ⑧ overlay → logo → lowerThird → effects → sectionCard → hook → sting   （package）
  ⑨ 片尾最后 0.9 秒淡出到黑
```

### 8.3 主播贴纸
- **对齐**：每张贴纸载入时扫描透明度找出包围盒，取最底下 6% 那一截的平均横坐标当「脚底中心」，画的时候脚底对齐到场景的脚底线。所以各张贴纸构图不一致也没关系。
- **说话弹动**：音量曲线里每个「字冒头」给一个弹簧冲量，贴纸纵向拉长、横向等比收窄（`sy = 1+s`，`sx = 1−0.6s`），弹簧带阻尼回弹；同时有左右摇摆弹簧；不说话时轻微呼吸。
- **换表情**：换图那一帧先压扁，同时给一个向上的速度，由跳跃弹簧带回原位；大动作跳得高。同一刻通知包装 `onSticker`。
- **缺图**：载入不到的贴纸用占位小人（主播代表色的圆头小人，胸口写名字和表情名），`qa` 会列出来。
（参数见 animation_rules.md）

### 8.4 摄像机
- 四个量：中心 x、y、缩放 z、旋转 r。
- 演播室里：镜头被带阻尼的弹簧拉向目标（全景 / 特写 / 倾斜 / 推近），推拉带一点过冲再停稳。特写对准场景里的主播站位、高度取贴纸上半身。
- 推大屏 / 出大屏：专门的缓动（加速冲进去、略冲过头再回稳；出来减速拉回带一点歪斜晃动），推到底时屏幕正好铺满画面。
- 视差：推进时主播和前景按不同系数放大，推得越深层次感越强。
- 不露边：每帧限制镜头——缩放不小于 1（倾斜、震屏时再多放大一点），视野永远在 1920×1080 的布景之内。

### 8.5 大屏实机画面
- 场景的 `screen` 是一块（最好 16:9 的）区域。推进时镜头缩放到正好铺满画面，实机画面就是全屏的。
- 片段帧按「当前时间 − 这段开始时间」× 30 取第几张，原速播放；不够长时定格在最后一张。
- 有黑边的片段只取有画面的部分，等比铺满。
- 推进途中主播逐渐透明、在铺满之前完全消失；大屏期间右下角显示当前说话人的小贴纸。

### 8.6 场景接口
`defineScene({screen, screen_frame, hosts, glow, palette, load, back, front})`。show.json 的 `scene` 里写的位置和颜色会覆盖脚本默认值，所以场景编辑器拖出来的数字对任何场景都有效。`back/front` 每帧拿到画布、时间和 `api`（载入图片、等比铺图、主播音量、谁在说话、大屏状态、默认屏幕待机画面、各种小工具）。详见 scene_rules.md。

`scene --export` 调用页面里的 `exportLayers()`：把 `back()`、`front()` 各画一次存成透明 PNG，再画一张参考线（屏幕框、主播站位和贴纸范围、脚底线、近景取景框、新闻栏和台标会盖住的区域）。

### 8.7 包装接口
包装脚本定义一个 `PKG` 对象：画图函数 `behindHosts / frontOfHosts / overlay / logo / lowerThird / effects / sectionCard / hook / sting`，事件函数 `effect / onSticker / event`，以及可选的 `load`。引擎在固定的时刻、固定的图层调用它们，并把字幕、栏目、快讯、时钟、转场、看点速报、主播位置和音量等状态以全局变量和 `hookState()` 提供。详见 package_rules.md。

### 8.8 渲染器（render.js）
- 用 playwright 打开本地网页服务上的渲染页。
- **虚拟时钟**：页面加载前替换掉 `performance.now`、`requestAnimationFrame`、`setTimeout`，由渲染器手动推进时间。每一帧：预载下一帧要用的片段图片 → 时间前进 1/30 秒 → 把 canvas 存成 jpg。不管电脑快慢，结果完全一样。
- **并行**：全片按帧数分给几个进程，每个进程从自己那段开始前 3 秒先空跑，让弹簧等状态进入正确状态，再开始存图。
- `--stills` 只截指定时间点；`--range` 渲染一段并合成带声音的预览；`--keep` 只补缺的帧；`layers` 模式给 `scene --export` 用。

### 8.9 编码与分段
- ffmpeg 把 `frames/%05d.jpg` 和 `master.wav` 合成 H.264（crf 25、码率上限 1.6M）+ AAC 160k。
- 在每个板块转场整屏盖住的那一刻（以及看点速报之后的片头）插关键帧；超过 `split_mb` 就在这些位置无损切段。
- 章节：每个板块从转场开始的时间（看点速报 00:00，正片第一个板块从片头开始）。

### 8.10 封面
`templates/cover/cover.html`，按 16:9 和 4:3 两套版式出图：片段画面做背景、游戏名大字、版本号、副标题、信息行、福利字、两位主播贴纸、游戏 logo。文字在 episode.json → cover 里改，版式改模板。

## 9. 声音是怎么做的

- **人声**：align 排好的两条人声轨。
- **音效**：全部用 numpy 程序合成（`sfxlib.py`），不用素材文件：pop、boing、whoosh、swoosh、zap、thump、twinkle、ding、hit。

  | 时机 | 音效 |
  |---|---|
  | 片头 | swoosh + hit |
  | 看点速报每条 | whoosh + hit（有气泡再加 boing） |
  | 换表情 | pop（大动作再加 twinkle） |
  | 要点贴纸 | boing |
  | 进 / 出大屏 | whoosh + zap / zap + whoosh_out + 落地 pop |
  | 板块转场 | swoosh + hit + swoosh |
  | 拍桌 / 感叹 / 闪亮 / 闪光 / 信息牌 | thump / boing / twinkle / zap / ding |

- **原声垫底**：只用标了「原声」的片段。响度统一后乘 `orig_level`（有【独奏】的段更响）；**主播说话时自动压低**；进大屏后淡入、出大屏淡出、同窗口换段交叉淡化。
- **混音**：人声 + 音效（× `sfx_level`）+ 原声，整体归一化。
- 不加 BGM（需要就后期配）。

## 12. 质量检查与返工

`qa` 自动查：两人声音重叠、片段缺失或太短、空字幕、帧是否齐全、还在用占位图的贴纸，并拼出转场和进出大屏的关键帧。然后逐条人工看（qa_checklist.md）。

| 改了什么 | 从哪里重跑 |
|---|---|
| 只改标记（表情、镜头、要点） | parse → align → stage → audio → render → encode |
| 改了台词 | dub → 重配 → align 起全部 |
| 重新配音 | align 起 |
| 片段时间点 | stage → clips（重截变了的）→ prepclips → audio → render → encode |
| 改了场景 / 包装 / 引擎 / 补了贴纸 | render → encode |
| 只改声音 | audio → encode |
| 只改封面 | cover |

## 13. 环境与已知限制

- 依赖：Python 3.9+（numpy、pillow）、ffmpeg、Node.js 18+（playwright + chromium）、中文字体（Windows 自带）。
- B 站相关操作在浏览器里做，AI 字幕需要登录。
- 渲染速度：2 核约 9 帧/秒，6 分钟成片约 20 分钟；`prepclips` 后 `work/` 有 1–3GB。
- 原视频本身的水印、官方字幕不会被处理；黑边里的水印会随黑边一起被裁掉。
- 换表情时的左右摇摆带一点随机，同一帧重渲可能有极细微差别，不影响观感。
