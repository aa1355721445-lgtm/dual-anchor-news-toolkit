# 动画规则（人物弹动、贴纸切换、摄像机）

画面里所有动作都由程序按下面的规则算出来，稿子里不用逐帧指定。
默认值是调好的一套手感；想调，在节目包的 `show.json` 里加一个 `animation` 块，只写要改的项，没写的保持默认：

```jsonc
"animation": {
  "talk":   {"amp": 1.3},                 // 说话弹得更明显
  "camera": {"closeup_zoom": 1.5}         // 特写推得更近
}
```
改完从 `stage` 起重跑（`stage` → `render` → `encode`），声音不用重做。

---

## 一、说话：整张贴纸跟着配音音量弹性拉伸

**原理**
1. `stage` 把每位主播的人声轨按每秒 60 格算音量（RMS），再按这个人声音的 95% 分位归一化到 0–1，得到音量曲线。
2. 每一帧检查音量曲线：出现「一个字冒头」——音量超过门槛、比上一格明显上升、而且高于最近的平均音量——就给贴纸一个向上的冲量。
3. 冲量推动一个**弹簧**：贴纸纵向拉长（`sy = 1 + s`），同时横向等比收窄（`sx = 1 − 0.6·s`），体积感不变；弹簧带阻尼，会回弹几下再停住，所以看起来是 Q 弹而不是机械抖动。
4. 每次冲量还会给一点随机的左右摇摆（也是弹簧），避免每个字都一模一样。
5. 不说话时保留一个很轻的呼吸起伏。

所以弹动的节奏完全跟着配音的字走：字密就弹得密，重音字（音量大）弹得高，停顿时自然静下来。

| 参数 `talk.*` | 默认 | 作用 | 调大会怎样 |
|---|---|---|---|
| `amp` | 1.15 | 每个字的冲量倍数 | 弹得更高、更夸张 |
| `freq` | 3.4 | 弹簧频率（次/秒） | 弹得更快、更「脆」 |
| `damp` | 0.26 | 阻尼（0–1） | 回弹次数更少、更稳；调小会晃更久 |
| `onset` | 0.18 | 算作「出字」的最低音量 | 轻声的字不再弹 |
| `rise` | 0.04 | 比上一格至少上升多少才算新字 | 只有明显的字头才弹 |
| `gap` | 0.11 | 两次弹动的最短间隔（秒） | 弹得更稀 |
| `kick` / `kick_lv` | 0.6 / 0.8 | 冲量 = kick + 音量 × kick_lv | 重音字和轻音字差别更大（加大 kick_lv） |
| `tilt` | 0.22 | 每个字带的左右摇摆量 | 摇头晃脑更明显 |
| `breath` | 0.008 | 不说话时的呼吸幅度 | 待机时起伏更明显 |

## 二、换表情（贴纸切换）：压扁 → 弹起 → 落地

**原理**
1. 稿子里的【贴纸】、【反应】或动作提示让贴纸换成另一张整图。
2. 换图的同一帧：贴纸先被**压扁**（纵向缩短 `pop`），同时给一个**向上跳**的速度；两个弹簧各自回弹，于是看到「一蹲—一弹—落稳」。
3. 动作大的表情（指、握拳、拍桌、吃惊、生气、得意、开心……）跳得高（`jump_big`），平静或慌张类跳得低（`jump_small`）。哪个贴纸算哪类见 `hosts.X.fxkind`，不写就按文件名猜。
4. 同一刻引擎通知包装层 `onSticker`，想在换表情时冒粒子就在那里做（package_rules.md）。
5. 从大屏回到演播室时，两人一起做一次「落地」：压扁 `land_squash` + 跳 `land_jump`。

| 参数 `switch.*` | 默认 | 作用 |
|---|---|---|
| `pop` | 0.17 | 换图瞬间压扁的程度 |
| `jump_big` / `jump_small` | 520 / 300 | 大动作 / 小动作表情的起跳速度 |
| `jump_hz` / `jump_damp` | 2.6 / 0.32 | 跳跃弹簧的频率和阻尼 |
| `land_jump` / `land_squash` | 620 / 0.16 | 从大屏回演播室时的落地跳 |

## 三、摄像机

**选哪个镜头**（`stage` 决定，规则见 staging_rules.md）：板块第一句、短句接话 → 全景；带「！」→ 说话人特写；【镜头】标记优先。

**怎么动**
1. **演播室里换镜头**：摄像机不是硬切，而是被一个**弹簧**拉向目标位置（带一点过冲再停稳），所以全景↔特写之间是顺滑带弹性的推拉。
2. **特写**：对准说话人，放大 `closeup_zoom` 倍。**倾斜**：偏向主播 A、放大 `dutch_zoom`、画面倾斜 `dutch_angle`（弧度，负数向左倾）。**推近**：从全景开始每秒放大 `push_rate`，最多放大到 1 + `push_max`。
3. **进大屏**：镜头先加速冲向屏幕（`wall_in` 秒），冲过头一点（`wall_overshoot` 倍）再回稳，推到底时屏幕正好铺满画面；推近途中两位主播逐渐透明直到完全消失（不会透到画面上）；第 `wall_flash` 秒屏幕切成实机画面。
4. **出大屏**：屏幕回到待机画面 → 镜头在 `wall_out` 秒内拉回全景，到位时带一点点歪斜晃动 → 两人落地一跳 → 如果下一句要特写，`return_delay` 秒后再推过去。
5. **板块转场**：转场盖住画面的那一刻，直接把下一个场景（大屏或演播室、镜头位置）摆好，转场退开时已经是新画面，没有推拉。

| 参数 `camera.*` | 默认 | 作用 |
|---|---|---|
| `spring_hz` / `spring_damp` | 1.5 / 0.58 | 演播室内镜头弹簧的速度 / 稳定度（阻尼小会晃过头更多） |
| `closeup_zoom` | 1.38 | 特写放大倍数 |
| `dutch_zoom` / `dutch_angle` | 1.3 / −0.05 | 倾斜镜头的放大和倾斜角 |
| `push_rate` / `push_max` | 0.06 / 0.4 | 推近镜头的速度和上限 |
| `wall_in` / `wall_overshoot` | 0.6 / 1.05 | 冲进大屏的时长、冲过头的比例 |
| `wall_flash` | 0.55 | 开始推进后第几秒切成实机画面 |
| `wall_out` | 0.62 | 拉回全景的时长 |
| `return_delay` | 1.5 | 拉回后多久再切到下一句要的特写 |

## 四、改不了 / 不建议改的

- 镜头的取景位置跟着场景走：特写对准 `scene.hosts` 的站位（高度取贴纸上半身），推大屏对准 `scene.screen`。换场景时自动跟着变。
- 想加新的动作类型（比如「点头」「转圈」），改 `engine/film_ctrl.js` 的 `stkUpdate` / `drawStickerAt`（改完直接生效）。
- 每次换表情的左右摇摆带一点随机，所以同一帧重渲可能有极细微差别，不影响观感。
