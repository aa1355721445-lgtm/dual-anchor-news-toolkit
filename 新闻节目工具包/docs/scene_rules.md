# 演播室场景：怎么做你自己的

场景 = 主播身后的布景 + 放实机画面的大屏 + 挡在主播前面的主播台。节目包 `show.json → scene` 决定用哪种：

| `type` | 是什么 | 适合 |
|---|---|---|
| `example` | 工具包自带的示例演播室（纯代码画，中性配色） | 先跑通流程、临时用 |
| `image` | 一张背景图 + 一张透明前景图 | 大多数人：在绘图软件里画好就行，不用写代码 |
| `code` | 你自己写的场景脚本（JS） | 想要会动的布景：滚动屏、闪灯、跟着说话变化的灯 |

三种都用同一套坐标和规则，切换只改 `type`。

## 一、坐标和几个关键数字

画面和场景都是 **1920×1080** 的「世界坐标」，原点在左上。镜头推拉都在这个坐标里算。

| 配置 | 意思 | 示例场景的值 |
|---|---|---|
| `screen` | 放实机画面的屏幕 `{x,y,w,h}`。**做成 16:9**（w:h = 16:9），实机画面就不会被裁边 | `{x:560,y:118,w:800,h:450}` |
| `screen_frame` | 可选。放画面时整块变暗的区域（比如整面屏幕墙比画面大一圈） | 比 screen 大一圈 |
| `hosts.A.x` / `hosts.B.x` | 两位主播脚底中心的横坐标。A 在左，B 在右 | 600 / 1320 |
| `hosts.base` | 脚底线：贴纸人物的最下沿落在这条线上。一般放在主播台后面，让台子挡住下半身 | 905 |
| `hosts.height` | 贴纸**整张图**在画面里的高度（不是人物本身的高度） | 640 |
| `hosts.cut_y` | 可选。低于这条线的贴纸被裁掉（没有前景台子、又不想露脚时用） | 不设 |
| `glow` | 可选。灯光参考点，给包装层做大屏泛光用 | 屏幕中心 |
| `palette` | 可选。颜色表，示例场景和代码场景用；图片场景用不到 | 见 example.js |

**硬约束**（违反了成片会难看）：
1. 下方新闻栏会盖住画面底部一条（高度 `ui.lower_third_height`，素白占位是 120 像素）。主播的脸、屏幕的主要内容不要放进这一条。
2. 左上角是台标位置，别放重要东西。
3. 场景要**铺满 1920×1080**：镜头推近、倾斜时会看到画面的任何一个角落，四边不能有空白。
4. 两位主播近景时镜头放大约 1.38 倍、对准主播上半身；推进大屏时镜头放大到屏幕正好铺满画面。屏幕离画面边太近会推不满（镜头不会推出布景之外），离主播太近会被主播挡住。
5. 屏幕上的待机画面（没放实机画面时）默认显示节目标题，所以背景图上的屏幕可以留空。

## 二、最快的路：导出示例 → 在绘图软件里改 → 用图片场景

```
python <工具包>/scripts/pipeline.py scene --show <节目包> --export
```
在 `节目包/场景/` 里生成：

| 文件 | 用途 |
|---|---|
| `导出_背景.png` | 主播身后的一切，1920×1080 |
| `导出_前景.png` | 主播台等挡在主播前面的东西，透明底，和背景对齐 |
| `导出_参考线.png` | 透明底参考线：屏幕框、主播站位和贴纸范围、脚底线、近景镜头取景框、新闻栏/台标会盖住的区域 |
| `导出_合成参考.jpg` | 三张叠在一起，一眼看清 |

在 Photoshop / Krita / Procreate 里把背景和前景当底稿重画（参考线放最上层对位，画完关掉），另存成 `场景/背景.png`、`场景/前景.png`，然后 show.json：

```json
"scene": {
  "type": "image",
  "dir": "场景",
  "background": "背景.png",
  "foreground": "前景.png",
  "screen": {"x": 560, "y": 118, "w": 800, "h": 450},
  "hosts": {"A": {"x": 600}, "B": {"x": 1320}, "base": 905, "height": 640}
}
```
屏幕和站位挪了位置，就用场景编辑器重新对一下（下一节）。

也可以完全不用导出图，直接拿自己画好的一张演播室图当背景：前景可以不要（没有主播台时可以设 `cut_y` 把贴纸下沿裁齐）。

### 图片场景的可选项
- `screen_idle`：屏幕没放实机画面时显示什么。`"title"`（默认）显示节目标题；`"none"` 就显示背景图里画的屏幕；写一张图片的文件名就显示那张图。
- `overlay`：再叠一张透明图在最上层（玻璃反光、前景虚化之类），会轻微呼吸。
- 背景图比例不是 16:9 也能用，会等比铺满裁边；最好就是 1920×1080。
- 图片场景是静止的。想让布景动起来用代码场景。

## 三、场景编辑器：拖出位置

双击打开 `新闻节目工具包/engine/场景编辑器.html`（离线可用）：
1. 载入 show.json、背景图、前景图；有贴纸就载入两位主播最常用的「默认」贴纸（没有就显示占位小人）。
2. 拖红框（大屏）到背景图的屏幕上，右下角圆点改大小（默认锁 16:9）。
3. 拖两个主播：左右拖改站位，上下拖改脚底线；人物头顶的圆点拖动改贴纸大小。
4. 「预览镜头」切到 A 近景、B 近景、推进大屏、倾斜看看：近景会不会切到奇怪的地方、推大屏能不能铺满。
5. 复制下面的 `"scene": {...}`，替换 show.json 里原来那段；或者「下载改好的 show.json」直接替换（先备份旧的）。

编辑器的镜头算法和渲染引擎一样，所见即所得；最后再用 `scene` 命令出一张真实渲染的预览确认。

## 四、预览：不用做任何一期就能看

```
python <工具包>/scripts/pipeline.py scene --show <节目包>
```
在节目包里生成 `场景预览.jpg`（6 个镜头：全景、A 近景、B 近景、推进大屏途中、大屏全屏、倾斜）和 `场景预览_全景.jpg`。用的是真的渲染引擎、你现在的包装和贴纸（没有的用占位）、一张彩条测试卡当实机画面。改完场景就跑一次。

## 五、代码场景：自己写

复制 `新闻节目工具包/engine/scenes/example.js` 到 `节目包/场景/scene.js`，show.json 写：
```json
"scene": {"type": "code", "script": "场景/scene.js"}
```
脚本所在的文件夹会整个拷进渲染网页，脚本里用 `api.image('xxx.png')` 载入同文件夹里的图。

脚本只做一件事：调用一次 `defineScene({...})`。

```js
defineScene({
  screen: {x:560, y:118, w:800, h:450},         // 同第一节的表
  screen_frame: {...}, hosts: {...}, glow: [x,y], palette: {...},
  async load(api){ this.bg = await api.image('墙.png'); },   // 可选：先载入图片
  back(g, t, api){ ... },     // 每帧画主播身后的一切（墙、地面、屏幕外框、屏幕待机画面）
  front(g, t, api){ ... }     // 每帧画挡在主播前面的东西（主播台、话筒），可省略
});
```
- `g` 是画布（Canvas 2D），坐标就是 1920×1080 世界坐标，镜头变换引擎已经做好了。
- `t` 是当前秒数，用来做动画。
- show.json 里写的 `screen`/`hosts`/`glow`/`palette` 会覆盖脚本里的默认值，所以场景编辑器拖出来的位置对代码场景同样有效。

`api` 里能用的：

| 名字 | 作用 |
|---|---|
| `api.scene` | 合并后的场景配置（`api.scene.screen`、`api.scene.hosts.A.x`…） |
| `api.pal` / `api.cfg` | 合并后的颜色表 / show.json 里原样的 scene 配置 |
| `api.image(路径)` | 载入场景文件夹里的图片（在 `load` 里 await） |
| `api.cover(g, 图, x, y, w, h)` | 把图等比铺满一个矩形 |
| `api.screenIdle(g, rect, t)` | 画默认的屏幕待机画面（节目标题） |
| `api.level('A')` | 主播 A 此刻的配音音量 0–1（做「谁说话谁那边亮」） |
| `api.speaking()` | 当前说话的主播 `'A'`/`'B'` |
| `api.footageOn()` | 大屏是不是正在放实机画面 |
| `api.show` / `api.ep` | show.json / episode.json |
| `api.rrect` `api.vgrad` `api.pxText` `api.mix` `api.hex` `api.rgb` `api.rnd` `api.lerp` `api.clamp` `api.easeBack` `api.mk` | 小工具：圆角矩形、色阶渐变、像素字、颜色混合、随机数…（见 engine/core.js） |

注意：
- `back` 每帧都会调用（30 帧/秒），里面别做很重的计算；固定不变的部分可以在 `load` 里先画到一张离屏画布（`api.mk(1920,1080)`），每帧贴上去。
- 实机画面由引擎画在 `screen` 上（在 `back` 之后、主播之前），不用你管。
- 灯光、粒子这些「效果」属于包装层（package_rules.md），不要写在场景里——场景只管布景本身。

## 六、检查清单

- [ ] `scene` 预览 6 个镜头里四边都没有空白、没有露出布景外面
- [ ] 主播脸不在新闻栏盖住的区域；近景时脸在画面中上部
- [ ] 推进大屏时实机画面铺满整个画面
- [ ] 前景台子挡住了贴纸的下沿，没有露出贴纸的底边
- [ ] 场景图片都在 `场景/` 里，`setup` 的节目包检查没有「场景：」开头的问题
