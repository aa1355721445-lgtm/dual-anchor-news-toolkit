# 交付前检查（必须逐条过）

**全片渲染完以后**跑 `pipeline.py qa`（自动项 + 关键帧拼图 `work/qa_关键帧.jpg`；帧不全它会报出来），再**亲眼看**拼图和成片。

## 自动检查（qa 会报）
- [ ] 两位主播的声音重叠 = 0 ms
- [ ] 每个片段都有画面，且片段时长 ≥ 需要的时长（不然最后一帧定格）
- [ ] 没有空字幕
- [ ] 哪些贴纸还是占位图（正式发布前要画好）

## 看画面
- [ ] **字幕完整**：整句显示，没有只显示一半、没有被名字挡住
- [ ] **新闻栏贴底**：左右和底边都贴着画面边缘，下面不露背景
- [ ] **画面四边不露黑**：镜头回弹、倾斜、震屏时，演播室边缘都不会露出黑边
- [ ] **大屏不透**：推进大屏后画面完全不透明，背后不能透出巨大的主播
- [ ] **台标**清楚，不挡重要画面
- [ ] 片段画面是游戏内容，**不是官方主持人的脸**，也不是错的时间点（对照关键点汇总或稿子里 🎬 后面写的说明）
- [ ] 片段如果自带黑边或水印（原视频本身的），告诉用户一声，由用户决定要不要换片段
- [ ] 要点贴纸不挡字幕、不在切换大屏时跳位置
- [ ] 板块转场标题对、序号连续；转场盖住画面的那一下没有露出镜头跳位
- [ ] 稿子里写的【特效】都有样子（素白包装会显示「【特效：xxx】」，正式发布前换成你的包装）
- [ ] 主播表情和台词情绪对得上（生气时不是在笑）

## 看点速报（开头）
- [ ] 只讲本期正片里有的内容，数字和正片一致；两人轮流，4–6 条，20–30 秒；收尾句和上一期不同
- [ ] 每条的实机画面对得上；看点速报 → 片头 → 演播室衔接没有黑帧
- [ ] 章节第一条是 `00:00 看点速报`

## 听声音
- [ ] **话没被打断**：每句的最后一个字完整，尤其是「——」接话和句尾语气词
- [ ] 一句话里没有混进稿子删掉的半句
- [ ] 原声符合 `audio.orig_rule`（建议不留 PV 音乐）；主播说话时原声明显变小
- [ ] 音效不盖过人声

## 交付物
- [ ] 成片（要从云端交付且有单文件大小上限时按板块分段；本机直接一个文件）
- [ ] 封面 16:9（1920×1080）和 4:3（1600×1200）：字不和背景糊在一起、主播贴纸不抢标题、右上角是游戏 logo
- [ ] 章节.txt：每个板块从转场开始的时间点
- [ ] 截片段清单 / 配音稿 留在本期文件夹，方便返工
- [ ] 用户的原视频没有被改动（只读）

## 返工的入口
| 问题 | 改哪里，从哪步重跑 |
|---|---|
| 只改标记（表情、镜头、要点） | 稿子.md → parse → align → stage → prepclips → audio → render → encode |
| 改了台词 | 稿子.md → dub → 用户重配 → align 起全部重跑 |
| 重新配了音 | 配音/ → align 起 |
| 片段时间点错 | 稿子 🎬 → align → stage → clips（重截变了的几段）→ prepclips → audio → render → encode |
| 只改了场景 / 包装 / 引擎 | 节目包 场景/ 或 包装/（或 engine/*.js）→ render → encode |
| 只改了声音 | audio → encode（帧不用重渲） |
| 只改封面 | episode.json → cover |
