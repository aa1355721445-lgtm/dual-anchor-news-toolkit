# 主播走位与实机画面

## 一、主播在画面里怎么动

**位置固定，不走位。** 两位主播一直站在场景给的位置上（`show.json → scene.hosts`，见 scene_rules.md）：A 在左、B 在右，贴纸脚底落在脚底线 `base` 上，贴纸整张图高 `height`。

她们只在原地动：说话时弹性拉伸、换表情时压扁弹跳、左右轻摇、呼吸起伏（规则见 animation_rules.md）。「谁在说话」靠这几样区分：说话的人在弹、字幕里是她的名字和颜色、需要时镜头给她特写；你的包装还可以加背光等提示（package_rules.md）。

**各个场景里主播在哪：**

| 场景 | 主播 | 其他元素 |
|---|---|---|
| 演播室 | 两人在场景给的位置 | 要点贴纸在说话人头部外侧（A 在左边、B 在右边），从上往下排，最多 3 个 |
| 推进大屏 | 两人随镜头放大（有视差），推到约 2 倍时开始变透明，到一定倍数前完全消失，不会透到实机画面上 | 演播室里的要点贴纸清空 |
| 大屏上 | **右下角出现「当前说话人」的小贴纸**（位置 `ui.corner_host`，默认高 360、脚底 y = 856），照样说话弹动、换表情；换人说话就换成另一位 | 要点贴纸集中到右上，有信息牌时往下让位 |
| 出大屏 | 镜头拉回全景后两人一起「落地一跳」 | 大屏上的要点贴纸清空 |
| 看点速报 | 由你的包装决定（素白版：说话的那位在右边，换人时滑进滑出） | — |

## 二、实机画面怎么展示

**从原视频到大屏：**
1. `clips` 从稿子里每个 🎬 的时间点开始，截「这段要播的时长 + 2.5 秒」，缩放并补边到 1280×720，**保留声音**，存成 `片段/w00s0.mp4`……（编号 = 第几次进大屏 + 第几个画面）。
2. `prepclips` 把每段拆成每秒 30 张图和一条音轨，并**检测上下（或左右）黑边**：整段里每一帧都是黑的那部分算黑边。
3. 渲染时，画面画在场景的屏幕区域（`scene.screen`）里，等比铺满；镜头推进后，这块区域正好填满整个 1920×1080，所以实机画面是**全屏显示**的。

**播放规则：**

| 规则 | 说明 |
|---|---|
| 速度 | 按原速播放，从这段的开头播起，不加速不慢放 |
| 片段不够长 | 最后一帧定格（`qa` 会报「太短」，重截长一点） |
| 黑边 | **自动放大填满大屏**，左右会裁掉一点（PV 常见的电影宽银幕比例），原视频黑边里的水印也会一起被裁掉。不想裁：在该段 🎬 说明里写「保留黑边」，或在 show.json 里设 `"footage": {"fill_letterbox": false}` 全部关掉 |
| 一句话里换画面 | `🎬 37:01 → 37:17@锚点`：说到锚点那个字时**直接切**到下一段（不加转场），原声在两段之间做 0.15 秒交叉淡化 |
| 连续几句在大屏上 | 用 `🎬 续`，画面接着播，不会退出再进 |
| 缺片段文件 | 大屏显示黑底，`qa` 会报 |
| 声音 | 默认静音；标了「原声」的段垫在配音下面，规则见 staging_rules.md |

**大屏上叠着的东西**：左上台标、下方新闻栏（你的包装）、右下说话人小贴纸、右上要点贴纸、信息牌。原视频画面里自带的水印、官方字幕不会被处理。

## 三、选实机画面的细则（写 🎬 时照这个挑）

1. **画面对得上台词**：说卡池就给卡池图，说技能就给技能演示，说地图就给地图实景。时间点从关键点汇总里取，写稿前对照截图确认。
2. **优先动态的实机画面**（战斗、跑图、演出）；静态的信息图（卡池表、福利表）只配数字类台词，停留不超过一两句话。
3. **不要官方主持人或真人出镜的画面**，也尽量避开满屏官方字幕/讲解字的画面（会和我们的字幕打架）。
4. **每个画面 3–15 秒**。一句话讲了好几件事，就用 `→ 时间@锚点` 在一句里换 2–4 个画面，每次换在说到那件事的字上。
5. **进出大屏不要太密**：进、出各约 1 秒的推拉，两次进大屏之间至少留一句演播室对话；同一件事连着讲用 `🎬 续`。
6. **留原声的段**必须落在没有官方讲解的时段（`speechmap` 查），而且符合 `audio.orig_rule`（建议只留实机音效、角色语音，不留 PV 音乐）。
7. **黑边和水印**：黑边会自动填满；画面中间的水印去不掉，挑画面时尽量避开，避不开就在交付时告诉用户。
8. 片段时间点以「秒」为单位就够，`clips` 会自动多截 2.5 秒，不用自己留余量。
