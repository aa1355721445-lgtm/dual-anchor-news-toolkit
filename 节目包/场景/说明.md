# 场景

演播室场景用的文件放这里。详见 `新闻节目工具包/docs/scene_rules.md`。

- 现在 show.json 里 `scene.type` 是 `example`（工具包自带的示例演播室），这个文件夹可以空着。
- 想用自己的图：运行 `pipeline.py scene --show <节目包> --export`，这里会出现 导出_背景.png / 导出_前景.png / 导出_参考线.png，照着重画后存成 背景.png、前景.png，再把 `scene.type` 改成 `image`。
- 位置用 `新闻节目工具包/engine/场景编辑器.html` 拖出来。
- 想写代码场景：把 `新闻节目工具包/engine/scenes/example.js` 复制到这里改名 `scene.js`，`scene.type` 改成 `code`。
